OrderManager

Etsy Order Importer & Invoice Tool

Bestellungen aus Etsy zentral verwalten Manage Etsy Orders in One Place

OrderManager ist ein privates Desktop-Tool, das Bestellungen aus verschiedenen Vertriebskanälen – darunter Etsy – in einer einzigen Oberfläche zusammenführt und die Rechnungserstellung automatisiert.

OrderManager is a private desktop application that consolidates orders from multiple sales channels – including Etsy – into a single interface and automates invoice generation.

📦 Was macht die App? What does the app do?

OrderManager ist eine private Desktop-Anwendung für den persönlichen Gebrauch. Sie wurde entwickelt, um Bestellungen aus mehreren Verkaufskanälen (u.a. Etsy) in einem einheitlichen System zu verwalten, den Bestellstatus zu verfolgen und Rechnungen automatisch zu generieren.

OrderManager is a private desktop application for personal use. It was built to manage orders from multiple sales channels (including Etsy) in a unified system, track order status, and automatically generate invoices.

Die App läuft vollständig lokal auf dem Computer des Shop-Betreibers. Es gibt keine Cloud-Infrastruktur, keine externen Server und keine Datenübertragung an Dritte.

The app runs entirely on the shop owner's local computer. There is no cloud infrastructure, no external servers, and no data transmission to third parties.

🔌 Verwendete Etsy API-Endpunkte Etsy API Endpoints Used

Die App nutzt ausschließlich folgende Endpunkte der Etsy Open API v3, um Bestelldaten des eigenen Shops zu lesen und den Versandstatus zu aktualisieren. Es wird kein Screen-Scraping verwendet.

The app exclusively uses the following Etsy Open API v3 endpoints to read order data from the owner's shop and update shipment status. No screen-scraping is used.

  • GET
    /v3/application/shops/{shop_id}/receipts
    Abruf der Bestellliste des eigenen Shops (gefiltert nach Status/Datum) Retrieve the list of orders from the owner's shop (filtered by status/date)
  • GET
    /v3/application/shops/{shop_id}/receipts/{receipt_id}
    Abruf der Details einer einzelnen Bestellung Retrieve the details of a single order
  • PUT
    /v3/application/shops/{shop_id}/receipts/{receipt_id}
    Aktualisierung des Versand- und Bestellstatus Update shipping and order status

OAuth Scopes: transactions_r, transactions_w

Verbundene Shops:Connected shops: 1 (ausschließlich der eigene Shop des Entwicklers) 1 (the developer's own shop only)
